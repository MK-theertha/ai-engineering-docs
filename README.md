# AI Engineering Docs

Learning documentation for becoming an **AI Engineer**, written as practical, beginner-to-advanced developer guides with diagrams, runnable Python examples, interview preparation and hands-on projects.

## Contents

| Track | Description |
|---|---|
| [Generative AI & Large Language Models](docs/pages/generative-ai-llm/README.md) | 14 chapters: LLM fundamentals, Transformers, prompting, LLM APIs, embeddings, RAG, vector databases, fine-tuning, frameworks, agents, MCP, evaluation & production, and 7 portfolio projects |

## How each chapter is organised

- **Why it matters** and **how it works internally**, with Mermaid diagrams
- **Python code examples** using the OpenAI, Anthropic Claude and Google Gemini SDKs and open-source tools
- **Real-world use cases**, **advantages and limitations**, **best practices and common mistakes**
- **Interview questions with answers**
- **Hands-on exercises and an assignment**
- **References** to official documentation
